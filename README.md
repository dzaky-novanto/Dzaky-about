# Dzaky Personal Portfolio (Minimalist TKJ Theme)

A completely rebuilt, minimalist, and clean static portfolio designed specifically for a TKJ (Teknik Komputer dan Jaringan) student.

## Features
- **Clean Aesthetic:** Removed the dark/comet theme. Replaced with a professional, white/blue minimal design that feels like a tech/infrastructure environment.
- **Abstract TKJ Art:** Minimalist node/network connection animation in the hero section.
- **Guestbook Feature:** Added a message board where visitors can leave a note. 
- **Anti-Spam Restriction:** The guestbook uses LocalStorage to ensure a device can only submit **one** message to prevent spamming.
- **Zero 404 Errors:** Flattened the file structure. `index.html` is exactly at the root directory, perfect for GitHub Pages or Vercel.

## Deployment (No 404 setup)
1. Extract this zip file.
2. Ensure you see `index.html`, `README.md`, and the `assets` folder directly (do not put them inside another sub-folder).
3. Upload to your GitHub repository.
4. Go to **Settings > Pages**, select the `main` branch, and save.
5. Your site will be live at `https://[your-username].github.io/[repo-name]`
